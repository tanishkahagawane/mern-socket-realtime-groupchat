# 💬 Real-Time Group Chat Application

A beginner-friendly **real-time group chat application** built with **React.js** and **Socket.IO**. This project demonstrates bidirectional client-server communication, instant messaging, user presence tracking, and live typing indicators using WebSocket technology.

## ✨ Features

- **⚡ Real-Time Messaging:** Send and receive messages instantly between connected users.
- **👥 Chat Rooms:** Enable multiple users to communicate within a shared chat room.
- **✍️ Typing Indicators:** Display when users are typing, optimized with debouncing.
- **🟢 User Presence:** Automatically notify users when someone joins or leaves the chat.
- **🔄 Live Communication:** Maintain continuous, low-latency communication between the frontend and backend.
- **⚛️ React Hooks:** Manage messages, connections, and component state using `useState`, `useEffect`, and `useRef`.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Real-Time Communication:** Socket.IO
- **Backend:** Node.js and Express.js
- **Communication Protocol:** WebSockets
- **State Management:** React Hooks

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. **Clone the repository**

   ```bash
   git clone <your-repository-url>
   ```

2. **Navigate to the project directory**

   ```bash
   cd <project-folder>
   ```

3. **Install dependencies**

   Follow the instructions in the frontend and backend directories if they have separate `package.json` files:

   ```bash
   npm install
   ```

4. **Start the application**

   Run the frontend and backend using the scripts defined in their respective `package.json` files.

   ```bash
   npm run dev
   ```

   *Note: Update these commands according to your project's actual directory structure and available npm scripts.*

- How to implement typing indicators using debouncing.
- How React Hooks manage dynamic UI updates and application state.
